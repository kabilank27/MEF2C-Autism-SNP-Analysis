Analysis Tools

The project documentation includes information about the following tools:

1. SIFT and PolyPhen-2 – Functional prediction.
2. I-Mutant 2.0 and MUpro – Protein stability prediction.
3. MutPred2 – Functional effect prediction.
4. I-TASSER – Protein structure modelling.
5. GROMACS – Molecular dynamics simulation.
6. STRING and GeneMANIA – Protein interaction analysis.
7. PyMOL – Protein structure visualization.
