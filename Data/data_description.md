
# Data Description

## Project
In-silico Analysis of Missense SNPs in the MEF2C Gene Associated with Autism.

## Gene
MEF2C

## Variants Studied
- R15P
- L38P
- L38Q
- C39R

## Data Information
This folder contains the input data and related information used in the computational analysis.

## Data Organization
- Gene and variant information
- Protein sequence information
- Protein structure files
- Additional input files used for analysis

## Note
Only publicly shareable and properly documented data will be uploaded to this repository.
