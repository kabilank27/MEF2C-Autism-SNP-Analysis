
# Selected MEF2C Missense Variants

## 1. Project Overview

This project investigates the potential effects of deleterious missense variants in the MEF2C gene associated with autism and neurodevelopmental disorders.

## 2. Variant Identification

- Total SNPs identified: 69,649
- Total missense variants identified: 301
- Deleterious variants predicted by SIFT: 34
- Variants selected for detailed analysis: 4

## 3. Selected Variants

| S.No | Variant | rs ID |
|---|---|---|
| 1 | R15P | rs1202957297 |
| 2 | L38P | rs397514655 |
| 3 | L38Q | rs397514655 |
| 4 | C39R | rs796052729 |

## 4. Prediction Results

The selected variants were evaluated using multiple computational tools:

- SIFT
- PolyPhen-2
- PANTHER
- SNP&GO
- PhD-SNP

The four selected variants were predicted to have potentially damaging effects.

## 5. Protein Stability Analysis

The selected variants were further investigated using:

- I-Mutant 2.0
- MUpro
- DynaMut2

## 6. Purpose of This Dataset

This file documents the selected MEF2C variants used for downstream protein structure, stability, molecular dynamics and interaction analyses.
