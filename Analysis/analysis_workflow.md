# MEF2C SNP Analysis Workflow

## Project Overview
This project investigates selected missense variants
in the MEF2C gene associated with autism.

## Variants Studied
- R15P
- L38P
- L38Q
- C39R

## Analysis Methods
- Protein structure modelling
- Molecular docking
- Molecular dynamics simulation
- Protein-protein interaction analysis
- Structural and functional analysis
