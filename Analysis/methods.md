
# Methods

## 1. Variant Selection
Four missense variants of the MEF2C gene were selected for computational analysis:

- R15P
- L38P
- L38Q
- C39R

## 2. Protein Structure Modelling
The protein structures were modelled using I-TASSER.

## 3. Molecular Docking
Molecular docking was performed to investigate possible molecular interactions.

## 4. Molecular Dynamics Simulation
Molecular dynamics simulations were performed using GROMACS for 100 ns.

## 5. Protein-Protein Interaction Analysis
STRING and GeneMANIA were used to explore protein interaction networks.

## 6. Structural Analysis
DSSP, STRIDE and Project HOPE were used for structural and functional interpretation.
