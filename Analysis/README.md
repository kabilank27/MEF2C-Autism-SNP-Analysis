Analysis Overview

The analysis includes:

1. Missense variant selection.
2. Protein structure modelling.
3. Molecular docking.
4. Molecular dynamics simulation using GROMACS.
5. Protein-protein interaction analysis.
6. Structural and functional interpretation.

This folder documents the computational methods and workflow used in the MEF2C project.
