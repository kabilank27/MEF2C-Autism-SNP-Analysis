Results Organization

The results are organized into the following categories:

1. Variant Identification – Selected MEF2C missense variants.
2. Functional Prediction – Computational predictions of variant effects.
3. Protein Stability – Predicted changes in protein stability.
4. Structural Analysis – Structural changes associated with selected variants.
5. Molecular Dynamics – Protein behaviour during 100 ns simulations.
6. Protein Interaction Analysis – MEF2C-associated interaction networks.

Purpose

This folder presents the computational findings and their interpretation.

Detailed prediction values are documented in the Data folder, while additional result figures will be included after verification.
